# 需求与验收规格

## 1. 目标与边界

交付一个可被 Kuikly 页面直接使用、具有产品级演示效果的通用图表组件库。首个稳定版本包含折线图、柱状图和遵循 Kuikly 规范的 Kotlin DSL；后续可在不影响稳定性的前提下评估面积、饼环、组合图和 Sparkline。组件以 Android、iOS 与 OpenHarmony 宿主为正式支持目标，并提供公共 API、可运行示例和验收证据。

P0 不绑定服务端数据请求、行业数据模型或不可验证的原生实现。长按追踪、水平平移、扩展图表、动态动画和 H5 Showcase 都属于候选增强项，必须经能力探针、范围确认和多端验证后才可升级为交付承诺。

## 2. 功能需求

| ID | 要求 | 完成定义 |
| --- | --- | --- |
| FR-01 | 折线图 | 展示一条或多条数据趋势线，支持 X/Y 轴、网格、数据点和空数据状态。 |
| FR-02 | 柱状图 | 展示分类数据对比，支持柱色自定义、数值标签、正/负值基线和空数据状态。 |
| FR-03 | 坐标与布局 | 自动计算可绘制区域、刻度、标签避让及边距；容器尺寸变化后重新布局。 |
| FR-04 | DSL | 通过 Kotlin DSL 配置数据、坐标轴、网格、系列、主题和回调；配置错误有确定处理方式。 |
| FR-05 | 基础交互 | 点击/按压命中最近数据点或柱，显示选中态与提示信息，并回调数据索引和原始数据。 |
| FR-06 | 动态数据 | 数据或样式改变后，图表按最新配置重绘，不保留失效选中项。 |
| FR-07 | 工程化 | 公共 API、KDoc、示例和测试与组件一同提交。 |
| FR-08 | 可扩展图表内核 | 折线、面积、柱状与组合图复用笛卡尔坐标、轴、Tooltip 和手势内核；新增类型不复制粘贴坐标逻辑。 |
| FR-09 | 竞争性体验 | 提供亮/暗主题、图例、平滑/直线切换、分组/堆叠柱、密集数据处理；候选手势需按探针结果开放。 |

## 3. 非功能要求

- 公共 API 不暴露平台原生类型；核心模型位于 `commonMain`。
- 同一输入在正式支持端得到一致的数据域、刻度、颜色和命中语义，允许字体字形带来的像素级差异。
- 非法数值（`NaN`、`Infinity`）不得导致渲染崩溃；过滤该项并可选记录诊断。
- 空数组、单数据点、重复 X 值、全部相等 Y 值、负值和超长标签均有明确展示结果。

## 4. 验收追踪表

| 验收项 | 对应需求 | 证据 |
| --- | --- | --- |
| 折线趋势、坐标轴、网格和交互可用 | FR-01、FR-03、FR-05 | 正式平台演示录屏/截图、交互测试结果。 |
| 柱色与数值标签可配置 | FR-02、FR-04 | 示例页面、配置单元测试。 |
| DSL 可独立集成 | FR-04、FR-07 | 文档代码片段在示例模块编译通过。 |
| Android/iOS/OpenHarmony 可运行 | FR-07 | 三端构建日志、真机或模拟器截图。 |
| API 文档与示例完整 | FR-07 | `docs/06`、`docs/07` 与 KDoc 评审。 |
| 交互与性能可感知 | FR-05、FR-09 | 点击/候选手势录屏、100/1,000/5,000 点性能记录。 |
| 扩展图表可复用 | FR-08 | 面积、饼环、组合、Sparkline 的统一 DSL 示例。 |

## 5. 完成定义

一个功能只有在公共 API 已定稿、单元测试和示例已添加、正式平台验证记录已填写、文档已同步后才算完成。最终仓库必须能从干净环境按发布文档构建，并附上 Issue 所需的仓库地址、运行录屏、截图和验收证据。
