# 需求与验收规格

## 1. 目标与范围

交付一个面向金融行情的 Kuikly 跨端图表组件库。首要目标是完成 Issue 所要求的折线图、柱状图和遵循 Kuikly 规范的声明式 Kotlin DSL；随后在同一笛卡尔内核上补齐行情交互、K 线与成交量组合。组件完成后，实际接入 Kuikly AI 股票行情 Demo，证明它可服务真实业务页面而非仅展示孤立样例。

本轮的可运行示例及验收平台是 **Android 与 H5**。iOS、OpenHarmony 保留为未来兼容目标，但没有 Android/H5 双端证据不得称为跨端交付完成。

## 2. 功能需求

| ID | 要求 | 完成定义 |
| --- | --- | --- |
| FR-01 | 折线图 | 支持一条或多条时间序列、坐标轴、网格、数据点、空态，以及点击 Tooltip。 |
| FR-02 | 柱状图 | 支持分类或时间序列柱、颜色、数值标签、正/负值基线与空态。 |
| FR-03 | 声明式 DSL | 通过 `ViewContainer` 扩展 + `ComposeView<Attr, Event>` 配置数据、外观、交互和回调；错误配置有明确失败信息。 |
| FR-04 | 十字光标与 Tooltip | 折线图长按/滑动按最近 X 槽选点，显示十字线、选中标记和格式化 Tooltip；释放后的保留行为可配置。 |
| FR-05 | 平移与缩放 | 支持受限的图表横向拖动和缩放，维护可恢复 `ChartViewport`，不越过数据边界，也不意外抢占外层滚动。 |
| FR-06 | K 线与成交量组合 | 按时间顺序绘制 OHLC 实体/影线与成交量柱，价格区和成交量区共享 X 轴及视口，并能被同一个十字光标选中。 |
| FR-07 | 数据更新与边界 | 输入快照变更后正确重绘、保留可恢复状态；空数据、单点、重复时间、非法数值、极值、超长标签和不完整 OHLC 有定义行为。 |
| FR-08 | Android/H5 示例 | 提供同一份 DSL 的 Android 与浏览器运行入口、截图/录屏及可复制的构建运行步骤。 |
| FR-09 | 文档与 API | 公共符号具备 KDoc；API 参考、示例、测试说明与实际实现一致。 |
| FR-10 | 股票行情 Demo 接入 | 在组件完成并通过门禁后，接入 Kuikly AI 股票行情 Demo，使用真实业务数据适配层与真实页面交互。 |

## 3. 优先级与依赖

| 里程碑 | 范围 | 进入下一阶段的门槛 |
| --- | --- | --- |
| M0：基础组件 | FR-01、FR-02、FR-03，以及点击选择和基础 Tooltip。 | Line/Bar DSL、公共模型、单元测试和 Android/H5 最小示例可运行。 |
| M1：行情交互 | FR-04、FR-05。 | 十字光标、滑动选点、平移/缩放在双端通过手势与边界测试。 |
| M2：行情图 | FR-06、FR-07。 | K 线/成交量组合与数据更新、边界、视觉回归通过。 |
| M3：交付与业务验证 | FR-08、FR-09、FR-10。 | 文档/KDoc、双端示例、证据包和 Kuikly AI 股票行情 Demo 均完成。 |

## 4. 非功能要求

- `commonMain` 公共 API 不暴露 Android、浏览器或其他平台原生类型。
- 同一输入在 Android 与 H5 上应得到一致的数据域、视口边界、选中项、Tooltip 内容和回调语义；允许字体栅格化造成像素级差异。
- `NaN`、无穷大和不完整行情数据不得导致崩溃。外部坏数据被过滤并可诊断；调用方 DSL 配置错误在构建时通过 `require` 报出字段名。
- 高密度数据不得让峰谷或原始索引丢失；若采用采样，渲染采样与回调原始数据必须明确区分。
- 真实股票行情 Demo 的网络请求、鉴权和错误重试属于业务层；图表只接收已规范化的不可变数据。

## 5. 验收追踪

| 验收项 | 对应需求 | 证据 |
| --- | --- | --- |
| 折线、柱和 DSL 可独立使用 | FR-01、FR-02、FR-03 | 编译通过的示例、单元测试、API/KDoc 审核。 |
| 十字光标、Tooltip、滑动选点可用 | FR-04 | Android/H5 交互录屏、手势测试结果。 |
| 平移与缩放不越界 | FR-05 | 双端视口、边界与外层滚动测试。 |
| K 线与成交量同窗联动 | FR-06 | OHLC/成交量样本截图、十字光标与 Tooltip 测试。 |
| 更新和异常数据安全 | FR-07 | 自动化测试、视觉回归和数据更新记录。 |
| Android 与 H5 可运行 | FR-08 | 构建命令、设备/浏览器信息、截图或录屏。 |
| Kuikly AI 股票行情 Demo 已真实接入 | FR-10 | 代码入口、运行录屏及与组件版本对应的说明。 |

## 6. 完成定义

一个功能只有在公共 API/KDoc、自动化测试、Android 与 H5 示例、文档和验收证据均已同步后才算完成。只有 M0–M2 通过后才能将组件接入 Kuikly AI 股票行情 Demo；Demo 接入不能代替组件自身的测试和跨端验证。
