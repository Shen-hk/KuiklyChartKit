# 视觉与交互规范

## 1. 绘制顺序与几何

绘制顺序固定为：背景 -> 网格 -> 坐标轴 -> 数据图形 -> 数据标签 -> 选中高亮 -> Tooltip。`plotRect` 是扣除标题、图例、轴标签、内外边距后的唯一数据绘制区域；任何线、柱、点均不得溢出它。Tooltip 由 Compose 覆盖层渲染，必要时翻转方向以留在整个视图内。

- X 轴采用分类标签或数值标签；标签过长时优先省略中间标签，再做截断，禁止相互覆盖。
- Y 轴采用漂亮刻度并保留零基线；全正/全负数据可由 `includeZero` 控制是否强制包含 0。
- 折线缺失/无效数据造成断点，不得跨越缺失值连线。
- 柱以零基线向正/负方向延伸；每个分类的可点击区域至少覆盖可见柱体。
- 饼环从十二点方向顺时针布局；非正值不参与角度计算，环形中心和扇区间隙不响应点击。
- 组合图先绘制分类柱、再绘制折线和点，二者共享分类槽与 Y 轴；图例颜色顺序为柱系列后接线系列。
- Sparkline 保留紧凑内边距并默认只绘制平滑线；轴、网格、图例和点不占用空间。

## 2. 默认视觉令牌

以下是首版拟定的默认主题，调用方可通过 `ChartTheme` 或系列配置覆盖：

| 令牌 | 默认值 |
| --- | --- |
| 背景 | `#FFFFFF` |
| 主文字 | `#1F2937` |
| 次文字 | `#6B7280` |
| 网格/分割线 | `#E9EDF3` |
| 默认系列色 | `#2F80ED` |
| 选中高亮 | 默认系列色的低透明度变体 |

折线默认 2f 宽、选中点 4f 半径；网格为 1f 浅色虚线；柱默认圆角 4f、分类间距为柱槽宽的 20%。这些值必须集中在 `ChartTheme`，以便亮/暗主题和品牌色替换。默认 Palette 使用蓝、青、橙、紫、绿六色，系列在颜色不足时循环但图例必须保留形状/描边差异。

线宽、圆点半径、柱间距和 Tooltip 圆角应由主题集中管理，不要以散落的魔法数字存在于 Renderer 中。文本基线必须按 Canvas 字体度量对齐，不能假设各端字体高度相同。

## 3. 基础交互

| 行为 | 规则 |
| --- | --- |
| 点击/短按 | 命中最近的可见数据项；折线以点中心和命中半径判断，柱以柱体包围盒判断。 |
| 命中成功 | 更新选中态，显示含系列名、标签和值的 Tooltip，调用 `onSelect`。 |
| 点击空白 | 清除选中态；若未来提供 `onClearSelection`，只在状态确实变化时回调。 |
| 数据更新 | 若选中项不存在或无效，自动清除，不向新索引迁移。 |
| 辅助反馈 | 选中图形使用描边/透明高亮，不能只靠颜色区别。 |
| 饼环点击 | 仅命中实际可见扇区；选中后描边并显示标签、原始值与占比。 |
| 组合图点击 | 线点命中优先；未命中线点时按柱体包围盒选择，并在回调中返回 `seriesType`。 |
| 长按并移动 | 折线图和面积图可在 `tooltip.trackerEnabled=true` 时显示垂直追踪线与随手指移动的 Tooltip；每次移动命中同一 X 槽的所有可见系列。该行为已完成 Showcase 验收。 |
| 水平平移（实验性） | 仅当 `interaction.enablePan=true` 且数据超过 `visibleItemCount` 时使用；拖动改变 `ChartViewport`，在首尾数据处钳制。当前仅有 Android/JS 编译和逻辑测试证据。 |

首版不承诺双指缩放和惯性滚动。追踪和平移均必须显式开启；平移不得抢占外层滚动容器的常规手势。

## 4. 边界状态

- 容器宽高为零：不绘制图形，也不计算可除零的比例。
- 可绘制区域不足以容纳标签：保留图形区域，按规则隐藏标签并记录调试信息。
- 空数据：显示可由主题配置的空状态文案，不画伪造刻度。
- 极端值：使用科学计数法或格式化器，避免文本溢出；数值格式由 `valueFormatter` 覆盖。
