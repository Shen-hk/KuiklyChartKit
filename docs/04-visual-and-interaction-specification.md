# 视觉与交互规范

## 1. 绘制区域与层级

所有坐标几何基于唯一的 `plotRect`；折线、柱、十字线和 K 线均不得溢出它。K 线组合图将 `plotRect` 分为上下两个区域：`pricePlotRect` 绘制价格，`volumePlotRect` 绘制成交量；二者共享同一条 X 槽和同一个 `ChartViewport`，但各自计算 Y 轴范围。

绘制顺序固定为：背景 -> 网格 -> 坐标轴/标签 -> 数据图形 -> 数值与末价标记 -> 选中高亮/十字光标 -> Compose Tooltip 覆盖层。Tooltip 必须在整个组件可视范围内翻转或平移，不能被价格区或成交量区裁切。

## 2. 行情图形规则

| 图形 | 规则 |
| --- | --- |
| 折线 | 无效数据造成断线，不能跨越缺失点连线；滑动选点时只高亮当前 X 槽的点。 |
| 柱状图 | 正负柱围绕零基线绘制；命中区域至少覆盖可见柱体。 |
| K 线 | 影线从 `low` 到 `high`，实体从 `open` 到 `close`；`open == close` 时仍绘制最小可见实体或横线，避免消失。 |
| 成交量 | 每根柱与同时间戳 K 线对齐；若 `colorByPriceDirection=true`，颜色跟随该 K 线涨跌方向。 |
| 末价线 | 仅在配置开启且有有效最后价格时显示；标签不能遮挡 Tooltip。 |

涨跌颜色不使用硬编码金融市场语义，统一由 `ChartTheme` 或 `kLine { upColor/downColor }` 配置；除颜色外，Tooltip 中必须明确给出涨跌方向或数值，避免只依赖色觉区分。

默认样式集中在 `ChartTheme`：折线宽度、选中点半径、网格线、K 线最小实体宽度、柱圆角、价格区/成交量区间距和 Tooltip 圆角均不得散落在 Renderer 中。文本基线按 Canvas 字体度量布局，不能假设 Android 与 H5 字体高度一致。

## 3. 十字光标、Tooltip 与滑动选点

| 行为 | 规则 |
| --- | --- |
| 点击/短按 | 命中最近可见数据项，更新单项选择并显示 Tooltip。点击空白区域清除选择。 |
| 长按开始 | 在按下位置吸附到最近可见 X 槽，绘制垂直十字线与选中标记，显示 Tracker Tooltip。 |
| 长按滑动 | 十字线始终限制在 `plotRect` 水平边界内；每次移动按同一个 X 槽更新价格、成交量和多系列数据。 |
| K 线 Tracker | Tooltip 顺序为时间、开/高/低/收、涨跌幅（若有基准）、成交量；无成交量时省略该行。 |
| 释放/取消 | `keepOnRelease=true` 时保留最后一个选中槽，否则清除 Tracker。取消事件不得触发错误的最终选择回调。 |

十字线为 1f 虚线，当前点或 K 线以描边/半透明底板突出。Tooltip 锚定选中槽附近；当右侧空间不足时翻转到左侧，当上下空间不足时在不遮挡手指/鼠标位置的前提下平移。

## 4. 平移、缩放与手势仲裁

| 手势 | 生效条件 | 结果 |
| --- | --- | --- |
| Tracker 滑动 | `enableTracker=true` 且长按已激活。 | 选择相邻 X 槽，不改变视口。 |
| 水平拖动 | `enablePan=true`、数据超出可视容量，且未激活 Tracker。 | 改变 `ChartViewport`，在第一根和最后一根处钳制。 |
| 缩放 | `enableZoom=true` 且平台能力探针通过。 | 以手势中心为锚点调整可视范围，限制在 `minZoom..maxZoom`。 |
| 纵向移动/外层滚动 | 图表未占有有效横向平移或缩放手势。 | 交给外层滚动容器；图表不应吞掉普通页面滚动。 |

平移和缩放结束后仅在视口实际变化时触发 `onViewportChanged`。缩放后 Tracker 若仍指向可见稳定数据项则保留，否则清除；不能把它映射到另一根 K 线。平台未通过缩放探针时隐藏或禁用缩放入口，不能仅以视觉动画伪装为已缩放。

## 5. 边界呈现

- 容器尺寸为零或 `plotRect` 不足：不绘制数据图形、不进行坐标除法，并显示可配置的空白/调试状态。
- 空数据：显示空态，不绘制伪造刻度、十字线或 Tooltip。
- 单根 K 线、全部相等价格、极小价差：扩展安全数据域，保证实体、影线、坐标与 Tooltip 可见。
- 超长日期、货币或成交量文本：先降低标签密度，再截断；不得互相覆盖、越界或遮挡十字光标。
- 新行情快照到达：避免闪烁和短暂错位；失效选择明确清除，视口是否跟随最新数据由配置决定。
