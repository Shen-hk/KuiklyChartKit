## 3. 面积图手动验收

1. 页面出现“累计趋势 / 近 8 日成交金额”，面积填充、边界线和横纵轴均可见。
2. 点击任一数据位置，卡片内反馈显示对应日期和原始成交金额。
3. 长按并左右移动，反馈日期与金额连续更新；松手后显示“面积追踪已结束”。
4. 面积边界为平滑曲线、数据点默认隐藏，半透明填充不遮挡网格和坐标标签。
5. 原有折线图追踪/平移和柱状图点击行为不回退。

## 4. 饼环图手动验收

1. 页面出现“占比洞察 / 渠道订单占比”，四个扇区、图例、百分比标签和中心“订单总量”均可见。
2. 扇区百分比分别显示约 42%、26%、19%、13%，中心总量显示 `1000 单`。
3. 依次点击四个扇区，卡片内反馈显示对应渠道、原始订单量和占比。
4. 点击环形中心、圆环外部或扇区间隙，不应产生新的选择反馈。
5. 原有面积、折线和柱状图交互不回退。

## 5. 组合图手动验收

1. 页面出现“目标对照 / 本周收入与目标”，五根实际收入柱与一条目标收入折线均可见。
2. 柱和线共用周一至周五分类槽，目标线点位于对应柱体中心线上方或下方。
3. 点击柱体，反馈显示“柱系列”；点击折线点，反馈显示“线系列”，日期和金额对应原始数据。
4. 折线点与柱体重叠或距离较近时优先选择折线点；点击远离线点的柱体区域应选择柱。
5. 原有饼环、面积、折线和柱状图交互不回退。

## 8. 性能基线

同一 JVM 单元测试进程内，每档重复执行采样 100 次：

| 输入点数 | 绘制点数 | 100 次总耗时 | 平均耗时 |
| ---: | ---: | ---: | ---: |
| 100 | 100 | 497 μs | 4 μs |
| 1,000 | 240 | 34,638 μs | 346 μs |
| 5,000 | 240 | 44,613 μs | 446 μs |

这些数字用于发现采样算法回退，不代表设备首帧、触摸延迟或帧率；正式性能结论仍需在 Android、iOS、OpenHarmony 记录设备信息和录屏。
