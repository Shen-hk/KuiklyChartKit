# 平台兼容与适配矩阵

## 本轮支持承诺

本轮的发布门槛是 **Android 与 H5**：两端都必须拥有可运行的行情 Showcase、交互录屏和验证记录。`chartkit` 的 JS(IR) 配置只是前提，不是 H5 支持证据；当前工作区缺少实际 `h5App` 宿主，因此 H5 示例是明确交付项。

iOS 与 OpenHarmony 仍可复用 `commonMain` 的纯 Kotlin 模型和布局，但本轮不作为发布门槛，也不得因编译配置存在就标记为已验证支持。

| 平台 | 当前工程基线 | 本轮承诺 | 必验能力 |
| --- | --- | --- | --- |
| Android | `minSdk 21`、`androidApp` 宿主 | 必须支持 | Line/Bar/KLine+Volume、点击/Tracker、平移/缩放、动态更新、边界数据。 |
| H5 | Kotlin JS(IR) 已配置；`h5App` 宿主待补齐 | 必须支持 | 浏览器加载、鼠标/触屏选择、Tooltip、平移/缩放、动态更新与边界数据。 |
| iOS | KMP target 已配置 | 待后续验证 | 不能以本轮结果宣称支持。 |
| OpenHarmony | 存在独立构建配置/宿主 | 待后续验证 | 不能以本轮结果宣称支持。 |

## 能力门槛与降级

| 能力 | Android | H5 | 不通过时 |
| --- | --- | --- | --- |
| 点击选择与 Tooltip | 发布门槛 | 发布门槛 | 该端不可发布。 |
| 长按/滑动十字光标 | 发布门槛 | 发布门槛；鼠标可用按下拖动或悬停等价实现，但语义要一致。 | 明确降级为点击，且不能宣称已完成 FR-04。 |
| 横向平移 | 发布门槛 | 发布门槛 | 禁用入口并记录探针结果。 |
| 缩放 | 发布门槛，前提是能力探针通过 | 发布门槛，前提是能力探针通过 | 若任一端失败，缩放从本轮范围移除或提供一致降级。 |
| K 线/成交量一致性 | 发布门槛 | 发布门槛 | 禁止只在单端显示组合图。 |

H5 至少需要完成桌面浏览器与触屏浏览器各一次实际验证；验证记录应写明浏览器及版本、输入方式、页面容器是否可滚动、JS 产物版本和截图/录屏地址。

## 一致性要求

- 相同 `ChartSpec`、数据快照与 `ChartViewport` 必须得到一致的时间排序、OHLC 校验、可视范围、X 槽选择和回调内容。
- 允许字体、抗锯齿和像素密度造成轻微视觉差异；不允许标签重叠、价格/成交量错位、Tooltip 越界、十字线选错 K 线或平移越过边界。
- 手势名称可随平台输入模型不同，但业务语义必须一致：Tracker 选择数据槽，Pan 改变视口，Zoom 改变视口比例。
- 所有颜色、边距和坐标使用 Kuikly 逻辑尺寸；业务层不得直接拼接 Android dp 或浏览器 CSS 像素来计算数据坐标。

## H5 宿主交付要求

1. 新增真实 H5 页面入口，并让它加载 `chartkit` 的 JS 产物与行情 Showcase。
2. 将构建、静态资源复制/部署、启动服务和访问地址封装为可重复命令；不得依赖个人机器的临时手工操作。
3. 在可滚动页面中验证图表手势仲裁；在鼠标和触屏输入下记录 Tracker、Pan、Zoom 的实际表现。
4. 将 H5 产物版本、浏览器信息、录屏和已知限制纳入发布证据。

## 验证记录模板

每次候选发布在 PR 或 `docs/evidence/` 中记录：平台、设备/浏览器、系统版本、Kuikly/JS 版本、构建命令、测试数据集、截图/录屏链接、已知差异、验证人和日期。没有证据的“已支持”不作为发布结论。
