# 平台兼容与适配矩阵

## 支持承诺

首版发布阻断平台是 Android、iOS 和 OpenHarmony。工程已配置 Kotlin Multiplatform 的 Android/iOS/JS 目标，并提供原生宿主；JS/H5 Showcase 可作为工程验证和演示补充，但在具备完整 Web 宿主、Canvas 证据和范围确认前不可标记为正式支持。

当前工程固定 Kuikly `2.7.0-2.1.21`。官方 Canvas 文档中展示的批量绘制、导出或手势能力必须先在此版本完成编译和实际验证，不能因“官方较新版本支持”而直接承诺。当前源码可编译 `toImage` 调用入口，但其注释未提供 Android/iOS/OpenHarmony 的统一承诺；ChartKit 仅以实验性 `DATA_URI` 封装它，不将其写入支持矩阵。

| 平台 | 当前工程基线 | 发布承诺 | 必验能力 |
| --- | --- | --- | --- |
| Android | `minSdk 21`，`compileSdk 34` | 支持 | 渲染、点击、动态数据、长标签、候选手势。 |
| iOS | deployment target `14.1` | 支持 | 渲染、点击、动态数据、长标签、候选手势。 |
| OpenHarmony | 现有 `ohosApp` 宿主 | 支持 | 渲染、点击、动态数据、长标签、候选手势。 |
| Web/JS | Kotlin JS(IR) 与 H5 Showcase | 实验性 | 仅记录构建和 Canvas 行为，不替代三端发布验收。 |

## 能力门槛

| 能力 | 优先级 | 门槛与回退 |
| --- | --- | --- |
| 点击 Tooltip | P0 | 三端均为发布门槛。 |
| 长按追踪、水平平移 | 候选 P1 | 先验证坐标和状态；任一正式平台不一致则保留点击模式。 |
| Canvas 命令批处理 | 候选性能优化 | 仅当前依赖可用时开启；必须保留等价回退。 |
| 导出图片 | P2 实验性 | 已封装一次性异步 `DATA_URI` 回调；完成 Kuikly 升级、三端回归、内存检查和真机证据后才可发布。 |

## 一致性要求

- 相同 `ChartSpec` 应得到一致的数据域、刻度数量、命中对象和回调内容。
- 可接受字体、抗锯齿、系统像素密度造成的轻微差异；不接受标签重叠、坐标反向、Tooltip 越界或命中错位。
- 所有颜色、边距与数据坐标按 Kuikly 逻辑尺寸处理；业务层不得直接拼接 Android dp、iOS pt 或 OpenHarmony px。
- 线性渐变、裁剪和文本测量可作为跨端基线；实验性能力不得表达必要信息。

## 验证记录模板

每次候选发布均在 PR 或 `docs/evidence/` 记录：平台、设备/模拟器、系统版本、Kuikly 版本、构建命令、测试数据集、截图/录屏链接、已知差异和验证人。没有证据的“已支持”不作为发布结论。
