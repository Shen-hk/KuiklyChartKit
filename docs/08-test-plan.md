# 测试计划

## 测试分层

| 层级 | 位置/方式 | 关注点 |
| --- | --- | --- |
| 单元测试 | `chartkit/src/commonTest` | 数据域、OHLC 校验、时间排序、刻度、坐标映射、视口钳制、采样与原始索引。 |
| 组件测试 | 组件模块或平台测试 | DSL 到 `RenderPlan`、数据更新、选择恢复、回调与主题优先级。 |
| 视觉回归 | Android/H5 截图对比 | 轴、K 线实体/影线、成交量、裁剪、十字线、Tooltip、暗色主题。 |
| 手势验收 | Android 真机/模拟器与 H5 浏览器 | Tracker、Pan、Zoom、外层滚动仲裁、取消事件。 |
| Demo 验收 | Kuikly AI 股票行情 Demo | 数据适配、真实页面更新、加载/空/错误状态与组件版本对应关系。 |

## 必测用例

| ID | 场景 | 预期 |
| --- | --- | --- |
| TC-01 | 正常多系列折线 | 点位、连线、轴、网格、图例与标签正确。 |
| TC-02 | 柱色、正负值与数值标签 | 颜色、零基线、格式化和值标签正确。 |
| TC-03 | 空数据、单点、全部相等 | 不崩溃；安全域、空态和单项绘制符合规范。 |
| TC-04 | 超长中英文标签与极值 | 无重叠、无越界，按密度规则隐藏或截断。 |
| TC-05 | 非法折线/柱数据 | `NaN`、无穷大和非法 DSL 参数被正确过滤或拒绝。 |
| TC-06 | 有效 OHLC K 线 | 实体、影线、涨跌色、末价线和成交量对齐。 |
| TC-07 | 非法/重复 OHLC | 反向高低值、缺字段、重复时间戳不会崩溃，诊断和过滤行为确定。 |
| TC-08 | 点击首、末和相邻数据 | 命中原始项与稳定 ID 正确，Tooltip 不越界。 |
| TC-09 | 长按与滑动 Tracker | 十字光标、Tooltip、价格和成交量始终对应同一 X 槽；取消不误回调。 |
| TC-10 | 平移边界 | 不能越过首尾数据；Tracker 未激活时平移，激活时只选点。 |
| TC-11 | 缩放边界与锚点 | 缩放中心、`minZoom`/`maxZoom`、平移边界和回调正确。 |
| TC-12 | 与外层滚动冲突 | 图表不吞纵向页面滚动；有效横向手势才占有 Pan。 |
| TC-13 | 新增/替换/截断快照 | 重绘稳定；按稳定 ID 恢复选择/视口，失效项按策略清除。 |
| TC-14 | 100/1,000/5,000 点 | 峰谷、原始索引和 Tooltip 仍正确；记录首帧与更新时间。 |
| TC-15 | Android/H5 视觉一致性 | 数据域、可见范围、选择与 Tooltip 内容一致，允许字体像素差异。 |
| TC-16 | Kuikly AI 股票行情 Demo | 真实数据适配层、加载/错误状态和组件交互可运行。 |

## 数据集要求

测试数据应固定并版本化，至少覆盖：连续上涨/下跌、十字星、跳空、高低价相等、零/缺失成交量、跨零柱、交易日间隔、重复时间戳、超长日期/证券名称和异常价格。不得只使用随机数据作为回归依据。

## 发布门禁

- `commonTest` 和受影响的平台测试全部通过。
- Android 与 H5 都跑完 TC-01 至 TC-15；缩放探针未通过时，必须在需求、API、示例中同步移除或明确降级，不能静默跳过。
- 每端记录设备或浏览器、系统、Kuikly/JS 版本、构建号、样本版本、截图/录屏和已知差异。
- M0–M2 全部通过后，Kuikly AI 股票行情 Demo 通过 TC-16；Demo 不能替代组件级测试。
- API/KDoc、文档、Android/H5 Showcase 与当前实现同步通过后，才可作为发布候选。
